# dguv-jats-schema

Dieses Repository enthält das XML-Schema (XSD), das zur Validierung der JATS-XML-Dokumente des DGUV Vorschriften- und Regelwerks verwendet wird.

Es handelt sich um eine Submenge bzw. eine Anpassung des offiziellen JATS-Publishing-Schemas.

Auf dem main-Branch befindet sich die aktuelle, von der DGUV bzw. deren Dienstleister bereitgestellte Version des Schemas.

Der develop-Branch enthält pro commit jeweils eine Anpassung des Schemas.
